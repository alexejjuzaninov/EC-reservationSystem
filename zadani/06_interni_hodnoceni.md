# C06 · Externí hodnocení

Týmu SW-DEV-AJVZMPIA nebyl podle sdělení týmu přidělen projekt jiné skupiny: zbývajících osm týmů se hodnotilo vzájemně. Externí assessment proto **nebyl proveden**. Bez cizí baseline nelze vyplnit nálezy, jejich ověření ani disposition; vlastní kontrola je nenahrazuje.

Pro náš projekt je doložena pouze interní kontrola konzistence:

| Kontrola | Výsledek |
|---|---|
| C02 ↔ kód | přechody a konflikty odpovídají `BookingService` a migraci V22 |
| C03 ↔ kód | diagram AS-IS odpovídá prototypu; cílové mikroservisy jsou označeny jako návrh |
| C04 ↔ měření | kritéria p95 jsou splněna jen pro 20 sekvenčních dotazů |
| C05 ↔ testy | schválení, zamítnutí a souběh mají HTTP i databázový oracle |

Záznam o nepřidělení je podklad pro vyučujícího; formální výjimku může potvrdit pouze vyučující.
